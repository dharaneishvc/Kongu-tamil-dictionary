பங்களிக்க · How to contribute

இந்த அகராதி இரண்டு முக்கிய CSVகளால் கட்டமைக்கப்படுகிறது — data/entries.csv மற்றும் data/categories.csv. முதன்மை உள்ளடக்கம் ஒரு கோப்பில் இருக்கிறது; குழுமப் பெயர்கள் ஒரு மாஸ்டர் CSV-இல் பராமரிக்கப்படுகின்றன. இது category_id (Foreign key) வழியாக இணைக்கப்படுகிறது; புதிய பிரிவு சேர்க்கப்பட்டால், வடிகட்டியில் தானாகவே தெரியும்.

The dictionary is structured around two CSV files: the main dataset at data/entries.csv and the category master at data/categories.csv. Entries point to a category via a foreign key such as category_id. Any new active group added there appears in the filters automatically; the first view still starts with All selected.

விரைவு வழி · The fastest route

கணினியில் எதையும் நிறுவ வேண்டியதில்லை. GitHub-இல் நேரடியாகவே திருத்தலாம். No local installation is required; you can edit the files directly on GitHub:

  1. data/entries.csv கோப்பைத் திறக்கவும் · Open data/entries.csv.
  2. ✏️ Edit பொத்தானை அழுத்தவும் · Select Edit.
  3. உங்கள் மாற்றத்தைச் செய்யவும் · Make your change.
  4. Commit changes → Propose changes · Commit and propose the change.
  5. Create pull request — அவ்வளவுதான் · Create a pull request.

உறுதியில்லையா? Not sure? பரவாயில்லை. ஆத்தா சொன்ன அரைகுறையாக நினைவிருக்கும் சொல் கூட மதிப்புமிக்கத் தரவே. Even an uncertain word remembered from family speech can be valuable data.

1 · புதிய சொல்லைச் சேர்க்க · Add a new word

முதலில் தேடுங்கள் · Search first. தேடல் எழுத்துப்பிழைகளைப் பொருட்படுத்தாது — பொடக்காலி, podakkaali, potakkali மூன்றும் ஒரே சொல்லுக்கே அழைத்துச் செல்லும். ஏற்கெனவே இருந்தால், சேர்க்காமல் அதைத் திருத்துங்கள். The search tolerates spelling differences. If the word already exists, edit that entry instead of adding a duplicate.

இல்லையெனில், கோப்பின் கடைசியில் ஒரு வரியைச் சேர்க்கவும். Otherwise, add one row at the end of the file:

id,headword,variants,latin,latin_variants,meaning_ta,meaning_en,examples,…
    ,ஒல்லு,,ollu,,நெல் குத்தும் செக்கு,husking mill,ஒல்லுல நெல்லக் குத்திட்டு வா,…
  • id நெடுவரிசையை காலியாக விடுங்கள் · Leave id blank; it will be assigned during review.
  • குறைந்தபட்சத் தேவை: headword + meaning_ta · Minimum required fields: headword and meaning_ta.
  • ஒரு examples வாக்கியம் சொல்லின் பயன்பாட்டைக் காட்டும் · An examples sentence is especially valuable because it shows the word in use.

2 · இருக்கும் வரியைத் திருத்த · Edit an entry

  1. தளத்தில் சொல்லைத் தேடி அட்டையைத் திறக்கவும்; கீழே 123 போன்ற எண் வடிவ id தெரியும். Search for the word and note its numeric id.
  2. CSV-இல் Ctrl+F மூலம் அதே id-ஐத் தேடவும். Find the same id in the CSV.
  3. அந்த வரியை மட்டும் திருத்தவும் · Edit only that row.

id-ஐ மாற்ற வேண்டாம் · Do not change the id. #/w/123 போன்ற பகிரப்பட்ட இணைப்புகள் அதைச் சார்ந்திருக்கின்றன. Shared links depend on it.

ஒரு சொல்லுக்குப் புதிய பொருள் சேர்ப்பது என்றால், புது வரி உருவாக்காமல் — அதே கட்டத்திலேயே சேர்த்துக்கொள்ளுங்கள். To add a meaning, extend the existing field instead of creating a new row:

- 123,கோடு,,kootu,,கடைசி,…
+ 123,கோடு,,kootu,,கடைசி | பக்கம் உயர்ந்த அடுப்பு,…

3 · இரட்டிப்பான வரிகளை இணைக்க · Merge duplicates

ஒரே சொல் இரண்டு வரிகளில் இருப்பது பிழை. இதைச் சரிசெய்ய · If the same word appears twice, merge the entries:

  1. சிறிய id உள்ள வரியை வைத்துக்கொள்ளுங்கள் · Keep the row with the smaller id.
  2. மற்ற வரியின் பொருள், வடிவங்கள், எடுத்துக்காட்டுகளை | கொண்டு அதனுள் சேர்க்கவும் · Combine meanings, variants and examples using |.
  3. இரண்டாவது வரியை முழுமையாக நீக்கவும் · Delete the second row completely.

4 · நெடுவரிசைகள் · Column reference

Column · நெடுவரிசைRequired? · கட்டாயமா?Description · விளக்கம்
idautoநிலையான எண் அடையாளம் (1, 2 போன்றவை). புதிய வரிக்குக் காலி; திருத்தும்போது மாற்றக்கூடாது.
headword✔தலைச்சொல், தமிழ் எழுத்தில். ஒரு வரிக்கு ஒன்று மட்டும் · The Tamil headword; one per row.
variants—அதே சொல்லின் வேறு வடிவங்கள்/எழுத்துமுறைகள் · Alternate forms or spellings.
latin—ஆங்கில எழுத்தில் ஒலிபெயர்ப்பு; மொழிபெயர்ப்பு அல்ல · Phonetic Latin romanization, not a translation.
latin_variants—ஆங்கில எழுத்தில் தட்டச்சு செய்யக்கூடிய மாற்று வடிவங்கள் · Alternate Latin spellings people may type.
meaning_ta✔தமிழ்ப் பொருள்; பல பொருள்களுக்கு | பிரிப்பு · Tamil meaning; separate multiple meanings with |.
meaning_en—ஆங்கிலப் பொருள் · English gloss.
examples—வழக்கு வாக்கியங்கள்; பலவற்றுக்கு | பிரிப்பு · Usage sentences; separate multiple examples with |.
word_type—பெயர்ச்சொல் / வினைச்சொல் / உரிச்சொல் · Noun / verb / adjective, and so on.
category_id✔முதன்மை பிரிவு குறியீடு; data/categories.csv-இன் id-யைச் சுட்டும் Foreign key · Category foreign key pointing to an id in data/categories.csv.
notes—சொற்பிறப்பு, வட்டார வேறுபாடு, ஐயங்கள் · Etymology, regional notes or uncertainties.
source_id—data/sources.csv-இன் id-யைச் சுட்டும் Foreign key; இந்தச் சொல்லுக்கான மூல(ங்கள்) · Foreign key into data/sources.csv naming the reference(s) for this entry; separate multiple sources with |.
image—images/-இல் உள்ள கோப்புப் பெயர் மட்டும் · The filename in images/, such as ollu.jpg, not a path.

5 · படம் சேர்க்க · Add an image

குழுமம் / Category setup: புதிய குழுமம் தேவை என்றால் data/categories.csv கோப்பில் ஒரு வரிசை சேர்க்கவும். அதில் id, label_ta, label_en, is_active ஆகியவை இருக்க வேண்டும். is_active=1 என்றால் அந்தக் குழுமம் வடிகட்டியில் தானாகத் தோன்றும். An active category appears in the filters automatically.

  1. படத்தை images/ கோப்புறையில் பதிவேற்றவும் — சிறிய எழுத்துப் பெயர், இடைவெளி இல்லாமல் (ollu.jpg) · Upload it to images/ with a lowercase name and no spaces.
  2. JPG அல்லது WebP, குறைந்தது 800px அகலம், ~300 KB-க்குள் · Use JPG or WebP, at least 800px wide and about 300 KB or less.
  3. அந்தச் சொல்லின் image கட்டத்தில் கோப்புப் பெயரை மட்டும் எழுதவும் · Put only the filename in the entry's image field.

தளம் தானாகவே அதை அட்டையில் சிறு படமாகவும், விவரப் பலகத்தில் முழு அகலத்திலும் காட்டும். The site will display it automatically; no code change is needed.

படம் நீங்கள் எடுத்ததாக, அல்லது வணிகப் பயன்பாட்டுக்கும் அனுமதிக்கும் உரிமத்தில் இருக்க வேண்டும். உங்களுடையது இல்லையெனில் மூலத்தை notes-இல் குறிக்கவும். Use an image you created or one with a licence that permits reuse; credit other sources in notes.

6 · CSV வடிவ விதிகள் · CSV format rules

  • ஒரு சொல்லுக்கு ஒரே வரி · One row per word. சேர்ப்பதற்கு முன் தேடுங்கள் · Search before adding.
  • ஒரு கட்டத்தில் பல மதிப்புகள் · Multiple values. | கொண்டு பிரிக்கவும் — கமா அல்ல · Use |, not commas.
  • கமா அல்லது மேற்கோள் உள்ள கட்டத்தை "…"-க்குள் வைக்கவும். உள்ளே ஒரு " வேண்டுமெனில் இரட்டிக்கவும்: "".
  • UTF-8, BOM இல்லாமல். Excel-இல் CSV UTF-8 எனச் சேமிக்கவும் — சாதாரண “CSV” தமிழை சிதைக்கும். LibreOffice Calc / Google Sheets பாதுகாப்பானவை.
  • தலைப்பு வரியையோ நெடுவரிசை வரிசையையோ மாற்ற வேண்டாம் · Do not change the header or column order.
  • ஐயமிருந்தால் சொல்லுங்கள் · State uncertainty. notes-இல் “உறுதிப்படுத்தப்படவில்லை” எனக் குறிப்பிடுங்கள்; யூகத்தை உண்மையாகச் சேர்க்க வேண்டாம் · Mark uncertain information instead of presenting guesses as facts.

7 · உள்ளூரில் சோதிக்க · Test locally

பக்கம் CSV-ஐ fetch() மூலம் ஏற்றுவதால், கோப்பை நேரடியாக உலாவியில் திறக்க முடியாது. The page loads CSV files with fetch(), so it needs a small local server: 

python -m http.server 8000
# http://localhost:8000

npx serve, php -S localhost:8000, VS Code Live Server — எதுவும் நடக்கும் · Any of these will work.

8 · அனுப்பும் முன் · Review checklist

  • சொல் ஏற்கெனவே இல்லை என இரு எழுத்துமுறையிலும் தேடிச் சரிபார்த்தேன் · I searched both scripts for an existing entry.
  • நெடுவரிசைகளின் எண்ணிக்கை மாறவில்லை (12) · The column count is still 12.
  • கமா உள்ள கட்டங்கள் மேற்கோளுக்குள் உள்ளன · Fields containing commas are quoted.
  • திருத்தத்தில் id தொடப்படவில்லை; புதிய வரியில் காலி · Existing id values were not changed; new ids are blank.
  • தளத்தை உள்ளூரில் ஏற்றிப் பார்த்தேன், வரி சரியாகத் தெரிகிறது · I tested the page locally and checked the entry.
  • பொருள் தமிழில்; ஆங்கிலம் இருந்தால் meaning_en-இல் · The meaning is in Tamil, with English in meaning_en when available.
